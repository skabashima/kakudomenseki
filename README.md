# 角度と面積

**図形の問題を、数字で撃ち落とせ。**

図形の「角度」と「面積」の問題を、中学受験・高校受験・大学受験の 3 コースで解く学習ゲーム。
問題は図形つきで出題され、答えの数値をキーパッドで入力して解く。
値は毎回ランダムに生成されるので、答えの丸暗記はできない。
スマホ縦持ちが基準。([さわる物理](https://github.com/skabashima/sawarubutsuri) と同じ構成の Godot プロジェクト)

## 動かし方

1. Godot 4.7 以降でプロジェクトを開く(`project.godot`)
2. F5 で実行(メインシーン: `scenes/main.tscn`)

CLI から:

```
godot --path "<このフォルダ>"
```

## コース(全 30 ステージ)

| コース | 内容 | ステージ例 |
|---|---|---|
| **中学受験レベル** | 小学校の図形。円周率は 3.14 | 三角形の角、平行線と角、おうぎ形、複合図形、葉っぱ形 |
| **高校受験レベル** | 中学数学 | 円周角の定理、三平方の定理、相似と面積比、座標平面、ヒポクラテスの月 |
| **大学受験レベル** | 数I・数II | 余弦定理、正弦定理、ヘロンの公式、内接円・外接円、ベクトル、弧度法、6分の1公式 |

各コースの中は易しい順に並び、前のステージをクリアすると次が開く(学年ではなく実力で進む)。
ステージの中でも 1 問目 → 3 問目でバリエーションが難しくなる。
無理数が出る問題は「√3 = 1.73 として」のように明記して小数で答えさせる。

問題はプロシージャル生成で、**問題文と答えの組だけ数えても約 7,000 通り**
(`tests/variation_report.tscn` で実測。図の数値の違いまで含めるとさらに多い)。
どのステージも数十通り以上のバリエーションがあり、周回・チャレンジで同じ問題ばかり出ることはない。

## ゲーム性

- **1 ステージ = ハート 3 つで 3 問連続ミッション**。まちがえるとハートが減り、
  0 になるとやり直し(数値は変わる)。クリア時は残りハートがそのまま **★1〜3** になる
- **得点 = 100 × 挑戦回数倍率 × ヒント倍率 × スピード倍率 × コンボ倍率**
  - 一発正解 ×2.0 / 2 回目 ×1.4 / 3 回目 ×1.0
  - ヒントを見るたび ×0.7(ヒントは「考え方」→「ほぼ式」の 2 段階)
  - 15 秒以内 ×1.3、30 秒以内 ×1.15
  - コンボは正解のたびに +0.1(最大 ×2.0)。まちがえると 0 に戻る
- **電卓内蔵 ― 紙とペンいらず**: 解答欄には数字だけでなく式が書ける
  (× ÷ + − ( ) √ に対応。例: `12×8÷2`、三平方なら `√(13×13−5×5)`)。
  「＝計算」で途中計算もでき、「こたえる」は式のまま採点される。
  こわれた式はハートを消費せずに教えてくれる
- **段位**: 総得点で 見習い → 図形たんけん隊 → 角度ハンター → 面積マイスター → 図形の達人 → 図形仙人
- **チャレンジ**: タイムアタック(3 分で何問。コース別/全コースミックス)/
  サバイバル(ミス 3 回まで。正解数が増えるほど難しいステージが出る)。自己ベストが残る
- まちがえたときは正解と解説を表示。リトライは別の数値で出題される

## 特徴

- **問題は全てプロシージャル生成**(`core/gen_*.gd`)。
  余弦定理がきれいに解ける辺の組、ヘロンの公式で面積が整数になる三角形、
  3.14 の計算が小数 2 桁に収まる半径と中心角、などを選んで生成する
- **図形は宣言的スペックから自前レンダラで描画**(`ui/figure_view.gd`)。
  多角形・円・おうぎ形・角の印・直角マーク・等辺チック・方眼と軸・関数のグラフ・
  葉っぱ形・ヒポクラテスの月まで対応。座標系は y 上向きで自動スケーリング
- **縦持ち最適化**: 論理解像度 1080×1920、iPhone のセーフエリア対応、
  日本語フォント(Noto Sans JP)同梱
- **効果音はプログラム生成**(外部アセットなし)

## iOS ビルド(Codemagic)

さわる物理と同じパイプライン。`codemagic.yaml` の `ios-kakudomenseki` ワークフローを
**手動で**回すと、Mac インスタンスで IPA をビルドして TestFlight へ自動アップロードする。
(自動トリガーは付けていない。Mac は分単価が高いので、上げたいときだけ回す)

流れ: 署名ファイル取得 → Godot 4.7.1 + iOS export テンプレート取得 → import ×2 →
`--export-release "iOS"` で Xcode プロジェクト生成(`export_presets.cfg` の iOS プリセット、
`application/export_project_only=true`)→ CFBundleDevelopmentRegion を ja に修正 →
署名して IPA → TestFlight。ビルド番号は Codemagic の `BUILD_NUMBER` で毎回ユニークになる。

事前に Codemagic 側で必要なもの(詳細は `codemagic.yaml` 冒頭のコメント):

1. App Store Connect integration に API キー `historygamekey`(アカウント単位・登録済みを使い回す)
2. 環境変数グループ `appstore_credentials` に `CERTIFICATE_PRIVATE_KEY`(Secret)
3. App Store Connect に Bundle ID `jp.snaplace.kakudomenseki` を登録

App Store 用の 1024×1024 アイコンは `store/icon/icon_1024.png`(透過なし)。
元 SVG から作り直すときは:

```
godot --headless --path . -s tools/make_icons.gd
```

## デバッグ

タイトル画面左下の「デバッグ: 全ステージ解放」トグルで、進捗に関係なく全ステージを遊べる(設定はセーブされる)。

## 構成

```
core/
  game_state.gd       進捗・セーブ・得点/コンボ/段位・テーマ・効果音 (Autoload)
  problem_gen.gd      コース/ステージ定義・生成の入口・図形スペックのヘルパー
  gen_elementary.gd   中学受験レベルの問題生成 (e1-e10)
  gen_junior.gd       高校受験レベルの問題生成 (j1-j10)
  gen_senior.gd       大学受験レベルの問題生成 (s1-s10)
scenes/
  main.gd/.tscn             タイトル(コース選択・段位・進捗)
  stage_select.gd/.tscn     ステージ一覧(★・自己ベスト・ロック)
  problem.gd/.tscn          問題シーン(ステージ攻略 / チャレンジ 共用)
  challenge_select.gd/.tscn チャレンジ選択
  records.gd/.tscn          記録(段位・コース別・チャレンジ自己ベスト)
ui/
  figure_view.gd   図形スペックを描く自前レンダラ
  drag_scroll.gd   指でなぞってスクロールできるようにする補助
tests/
  gen_check.tscn         全ステージ × 多数シードの生成検証 (--headless 可)
  play_check.tscn        実際に解答してクリア/失敗/★の検証 (--headless 可)
  smoke.tscn             全シーンのロード確認 (--headless 可)
  variation_report.tscn  ステージごとの問題バリエーション数を実測 (--headless 可)
  shots.tscn             全画面のスクリーンショット撮影(要描画環境)
```

テスト実行例:

```
godot --headless --path "<このフォルダ>" res://tests/gen_check.tscn
godot --headless --path "<このフォルダ>" res://tests/play_check.tscn
godot --headless --path "<このフォルダ>" res://tests/smoke.tscn
```
