### アプリ名(30字以内)
```
図形ハンター ― 角度と面積の受験対策
```
(19字)

### 短い説明(80字以内)
```
中学受験から大学受験まで角度と面積の全65ステージ。学年ごとに地図を進むストーリー付き。値が毎回変わるので暗記できません。
```
(60字)

### 詳細な説明(4000字以内)

```
■ 中学受験・高校受験・大学受験の図形を、1本で

図形ハンターは、図形の「角度」と「面積」の問題だけを集めた学習ゲームです。
小学生の受験算数(平面図形・立体)から、高校の三角比・ベクトル・積分までを
全65ステージに収めました。学年が上がっても、同じアプリで続けられます。

■ 小学生でも読める ― ふりがな付き

中学受験レベルのステージと、小学生向けのストーリーでは、
小学1年生で習う漢字だけをそのまま出し、**それ以外の漢字にはすべて
漢字の上にふりがな**が付きます。問題文も「〜を求めなさい」ではなく
「〜は?」のように短くしています。

■ 学年ごとに3つのストーリー

・ストーリー(小学生) 「たからのちず」全23歩
　1まいの地図を、はまべ → もり → かわ → どうくつ → やま → たにま とたどって、
　いちばん奥のたからばこを目ざします。**単元1つが地図の1歩**。1歩すすむごとに
　旗が立ち、その先にかかっていた**きりが晴れて地図がひろがります**。
　1歩の中身は、**指でさわって自分で見つける回**。三角形のかどをちぎって
　一直線にならべる、円をころがして直径3個分と少しを数える、水を移して深さが
　変わるのを見る ―― 公式を読む前に、手で確かめます。
　最後にその単元の問題を1問解くと、地図の上の自分が次のばしょまで歩いていきます。

・ストーリー(中学生) 「はかる旅」全21章
　章えらびは一覧ではなく**測量野帳の街道図**。三角点をたどって国を測り進み、
　町・橋・塔を越えていきます。その先は「まだ測っていない」霧に隠れ、
　1章クリアするごとに測量士がつぎの三角点まで歩いて霧が晴れます。
　中身は、図を動かして「動かしても変わらないもの」を自分で見つけていく物語。
　行く先々に公式を高く売りつける渡りの学者が先回りしていて、
　その言い分が本当かどうかは自分で測って確かめるしかありません。
　小学校の復習から中学の内容までを、章を追って進みます。

・ストーリー(高校生) 「軌道計算室」全9章
　こちらは**星図**。探査機を飛ばしながら惑星から惑星へ軌道をつなぎ、
　最後は遠い恒星に届きます。舞台は移住船が着いたばかりの惑星。
　着陸地点・中継塔・通信範囲・打ち上げの軌道を数学だけで決めていきます。
　方べきの定理・余弦定理・正弦定理・弧度法・円の方程式・積分が実際の道具になります。

　※ 中学生・高校生の答えも本編と同じ電卓入力です(選択肢ではありません)。
　　 計算しないと出せない問いなので、式のまま入れて「＝計算」もできます。

■ 答えの丸暗記ができません

問題はすべてプログラムがその場で作ります。同じ「時計の針の角」でも、
出るたびに時刻も答えも変わります。問題文と答えの組だけ数えて30,763通り。
「一度解いた問題集は二度目が効かない」という悩みがありません。

■ 図で出る。数字で答える。

1ステージはハート3つで3問連続のミッション。まちがえるとハートが減り、
0になるとやり直し(数値は変わります)。残ったハートがそのまま星1〜3個になります。

【角度編 20ステージ】
三角形の角・平行線と角・二等辺三角形・時計の針・多角形の角・正多角形と対角線・
ブーメラン形・折り返し・対頂角と外角・平行線と三角形・星形の角・円周角の定理・
円と接線・弧の比と円周角・作図でできる角・三角形の五心・三角方程式・
ベクトルのなす角・2直線のなす角・空間のなす角

【面積編 45ステージ】
正方形と長方形・三角形の面積・いろいろな四角形・円とおうぎ形・道の面積・
複合図形・長方形の中の点・底辺の比と面積比・葉っぱ形・立体の体積と表面積・
展開図と組み立て・水そうと水位・図形の移動と重なり・相似で長さを出す・立体の切断・
三平方の定理・特別な直角三角形・おうぎ形の計算・相似と面積比・平行線と線分の比・
相似比と体積比・座標平面の面積・ヒポクラテスの月・角錐と円錐・空間の三平方・
多面体とオイラー・方べきの定理・チェバとメネラウス・二等分線と中線定理・
余弦定理・正弦定理と外接円・三角比の面積公式・ヘロンの公式・内接円と外接円・
ベクトルと面積・弧度法・点と直線の距離・円の方程式・領域と最大最小・
空間図形の体積・空間ベクトルと平面・放物線と直線(6分の1公式)・2つの放物線・
面積の総合問題・回転体と曲線

各編の中は 中学受験 → 高校受験 → 大学受験 の順に並び、
前のステージをクリアすると次が開きます。

■ 解法そのものが変わる「挑戦 10問」

クリアした単元には「挑戦 10問」が出現。1問ごとに難度が上がり、
数字だけでなく解法そのものが変わります
(平行線と角なら 錯角 → 同側内角 → 折れ線 → ジグザグ → ジグザグの逆算)。
1ステージあたり2〜6種類、全体で約245種類の解法を用意しました。
10問そろえて王冠を獲得できます。

■ 紙とペンいらず ― 電卓内蔵

解答欄には数字だけでなく式が書けます(× ÷ + − ( ) √ に対応)。
「12×8÷2」でも「√(13×13−5×5)」でもそのまま採点。
「＝計算」で途中計算もでき、式のかたちがおかしいときはハートを減らさずに教えます。
本編・チャレンジだけでなく、**3つのストーリーすべてで同じ電卓**を使います。

■ わからないときは「解き方」を1ステップずつ

押すたびに解き方が一段ずつ進みます。時計の針・折り返し・葉っぱ形・
ヒポクラテスの月などの看板問題では補助線がスッと引かれ、注目する部分に色がつき、
等しい角に印がつきます。図の上に自分で補助線を引くこともできます
(頂点・辺の中点・円の中心にスナップ)。補助線はストーリーの依頼でも、
小学生の「しるし」の問題でも使えます(小学生には「せんを ひく」と表示)。

■ 続けられるしくみ

・段位 ― 見習い → 図形たんけん隊 → 角度ハンター → 面積マイスター → 図形の達人 → 図形仙人
・コンボ ― 正解のたびに得点の倍率が上がる。まちがえると0に戻る
・チャレンジ ― 3分タイムアタック / ミス3回までのサバイバル。自己ベストが残る
・星とスコア ― ステージごとに自己ベストが残る

■ こんな人に

・中学受験の算数で、平面図形の応用問題を数多く解きたい小学生
・高校受験の数学で、円周角や三平方の定理を確実に取りたい中学生
・共通テスト・大学入試に向けて、三角比と面積の計算を速くしたい高校生
・図形の問題集を1冊解き終えてしまい、次の問題が欲しい人

■ 安心して使えます

・広告は一切ありません
・通信も行いません(課金の処理をのぞき、すべて端末内で完結)
・個人情報を一切収集しません
・買い切り。サブスクリプションや追加の課金はありません

■ 無料で使える範囲

・角度編・面積編それぞれ最初の4ステージ(計8ステージ)
・タイムアタック(角度編)
・電卓、「解き方」アニメ、補助線、ヒント、段位、記録

残り57ステージと、全ステージの「挑戦 10問」、チャレンジのすべては
買い切り¥500ですべて解放されます(1回だけのお支払い)。
```
