# Nintendo Switch デベロッパー申請 ― 図形ハンター

Nintendo Developer Portal の申請フォームに**そのまま貼れる形**でまとめたもの。
数字は実測値(`tests/variation_report` / `README.md`)に合わせてある。

**注意**: この文は「Switch 版としてこう作る」という計画を書いたもの。
現行のスマートフォン版は縦持ち・タッチ専用なので、下に書いた
横画面 UI・コントローラー操作・HD 振動は**これから実装する分**が含まれる。
申請が通ったあと、ここに書いたとおりに作ること(§3 の宿題)。

---

## 1. 本タイトルのゲーム概要(Joy-Con 用のコントローラーマッピング、プレイヤー設定などを含む)

```
【ジャンル】図形(角度・面積)に特化した 1 人用の学習パズル

【概要】
小学校の受験算数から高校数学までの「角度」と「面積」の問題だけを集めた学習ゲームです。
問題はすべてプログラムがその場で生成するため、同じ問題が繰り返し出ることがありません
(問題文と答えの組で 30,832 通りを実測)。答えは選択式ではなく数値入力で、解答欄には
「12×8÷2」「√(13×13−5×5)」のような式をそのまま入力でき、内蔵の電卓が採点します。

収録内容は次のとおりです。
・角度編 20 ステージ + 面積編 45 ステージ(計 65 ステージ)。三角形の角や円周角から、
　三平方の定理、余弦定理、点と直線の距離、回転体の体積までを一本で扱います。
・学年別の 3 つのストーリーモード(小学生向け「たからのちず」23 話 /
　中学生向け「はかる旅」21 章 / 高校生向け「軌道計算室」9 章)。
　公式を読む前に、図形を指やスティックで動かして自分で決まりを見つける場面が入ります。
・陣取り型の戦略モード「島取り」(24 島・337 問)。解いた答えの数だけ陣地が広がります。
・「展開図マスター」(展開図 101 通り)。展開図がどの立体になるかを当てると、
　その場で展開図が立ち上がって立体に組み上がるところが見られます。

小学生向けの文章はすべて漢字にふりがなが付き、対象年齢は 6 歳以上を想定しています。

【プレイ人数】1 人。ローカル・オンラインともマルチプレイヤーはありません。

【プレイヤー設定】本体のユーザーごとにセーブデータを分けて保存します。クリア状況・
段位・自己ベスト・購入状態はユーザー単位で独立し、他のユーザーの進捗に影響しません。

【コントローラーマッピング(Joy-Con / Nintendo Switch Proコントローラー)】
・左スティック / 十字ボタン … カーソル移動。メニュー・ステージ選択、数字キーの移動
・A … 決定、数字の入力、次へ進む
・B … もどる、入力の 1 文字削除
・X … 「解き方」。補助線が 1 段ずつ引かれる解説アニメーションを進める
・Y … 補助線モードの切り替え。図の上に自分で線を引く
・右スティック … 補助線を引くときのポインタ操作。頂点・辺の中点・円の中心に吸着します
・L / R … 図と数字キーパッドのフォーカス切り替え、ステージの前後移動
・ZL / ZR … 図の拡大・縮小
・＋ … ポーズと設定(BGM のオン/オフ)
・− … 記録画面(段位・自己ベスト・コース別の進捗)
・携帯モードとテーブルモードでは、タッチスクリーンでも同じ操作ができます
　(ボタン操作との併用可)。すべての操作はボタンだけでも完結します。
```

## 2. 本タイトルではどのように Nintendo Switch の機能を利用しますか(マルチプレイヤー、携帯モードの可否、ドックの要否、HD振動など)

```
【マルチプレイヤー】使用しません。1 人用タイトルです。おすそわけプレイ、ローカル通信、
オンライン対戦・協力はいずれも行いません。

【携帯モード】対応します。タッチスクリーンでの操作(図をなぞって補助線を引く、
数字キーを押す)に対応し、携帯モード単体で最初から最後まで遊べます。

【テーブルモード】対応します。1 人用のため画面の共有や向かい合っての対戦はありません。

【TV モード / ドックの要否】対応しますが、ドックは必須ではありません。ドックなしでも
すべての機能を利用できます。

【解像度】TV モード 1920×1080、携帯モード 1280×720。現行のスマートフォン版は
縦持ち(1080×1920)ですが、Switch 版は横画面(16:9)向けに画面構成を作り直し、
図形を中央に大きく表示し、数字キーパッドと操作ガイドを左右に配置します。

【HD 振動】使用します。正解したとき、図形のピースが所定の位置に収まったとき、
展開図が立体に組み上がったときに、短く控えめな振動でフィードバックします。
強い振動や長い連続振動は使用しません。振動のオン/オフは設定から切り替えられます。

【セーブデータ】本体保存メモリーに保存します(1 ユーザーあたり数十 KB)。
microSD カードは使用しません。セーブデータのクラウド保存には対応する予定です。

【ネットワーク】使用しません。オンライン通信、ランキング、アカウント連携、
ユーザー生成コンテンツの送受信はいずれも行わず、すべて本体内で完結します。

【使用しない機能】amiibo、ジャイロセンサー、モーション IR カメラ、
NFC、追加ダウンロードコンテンツ、アプリ内課金(Switch 版は買い切りのみ)。

【その他】ゲーム内に広告はありません。表示言語は日本語のみ(発売リージョンは日本)。
文字はゲーム内に同梱したフォントで描画するため、本体のフォントに依存しません。
音はすべてプログラムで生成しており、外部の音源素材は使用していません。
```

## 3. 申請後にやること(この文のとおりに作るための宿題)

| やること | いまの状態 |
|---|---|
| 横画面(16:9)の UI | スマートフォン版は縦持ち専用(1080×1920)。作り直しが必要 |
| コントローラー操作 | いまはタッチ専用。フォーカス移動と上記のボタン割り当てを実装する |
| HD 振動 | 未実装 |
| セーブのユーザー分け | いまは 1 つ(`user://save.json`)。Switch のユーザーごとに分ける |
| 課金の扱い | スマートフォン版は買い切り ¥500 のアプリ内課金。Switch 版は本体価格に含め、アプリ内課金なしにする |
| 年齢レーティング | CERO の取得が必要(教育タイトルなので A 想定) |
