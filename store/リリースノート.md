```

■ 「全ステージを解放」が 買えなかった 件
App Store 側で 商品が まだ 使える 状態に なっておらず、購入しようとすると エラーに なる ことが ありました。ご迷惑を おかけして 申し訳ありません。商品の 登録を 出しなおしています。

### 変更の 記録(社内用)

| 変更 | 中身 |
|---|---|
| 原因 | App Store Connect の App 内課金が この バージョンの 審査に 含まれておらず、StoreKit が 商品を 返さない(「SKU not found」)。アプリ側の 不具合では ない |

### App Store「このバージョンの新機能」(4000字以内)

```
1.2 のあたらしいところ

■ 解き方アニメを ぜんぶの ステージへ
「解き方」を おすと、図の 上に 補助線が 引かれ、色が つき、1 手ずつ 進みながら 答えまで たどりつきます。これまで 一部の ステージだけだった この アニメを、中学受験と 高校受験の ぜんぶの ステージに 用意しました。三角形の 角、マスを しきつめる 面積、道を はしに 寄せる 考え方、円周角と 弧の 比、立体の 切り口 ―― どこから 始めても、まず 目で 見て つかめます。

■ 音と 手ざわり
BGM を 3 曲、効果音を 足しました。正解の ときは 図が 光って はずみ、続けて 当てるほど 音が 上がっていきます。音は 設定から 個別に 切れます。

■ まちがえた 問題の 復習
まちがえた 問題を おぼえておいて、あとの 出題に そっと まぜます。解ければ 消えます。苦手な ところだけ 自然に くり返せます。

■ 今日の図形
毎日 1 問だけ 出る 問題を 足しました。何日 続いたかが 記録され、結果は 答えを ふせたまま 共有できます。

■ 図鑑と キャラクター
進めた ステージが カードで 並ぶ 図鑑を 足しました。ストーリーでは 話している キャラクターの 絵が 出るように なりました。

■ 直したところ
・たからのちず: 平行四辺形・折り返し・時計・多角形の 回を、本編と 同じ 図と さわり方に そろえました。
・島取り: 「やさしい」を えらんだのに 上の 段の 問題が 出ることが ありました。
・全体の つじつま(ステージ・島・ストーリーの つながり)を 見る 検査を 足し、出荷前に 自動で 通しています。
```

### 変更の 記録(社内用)

| 変更 | 中身 |
|---|---|
| 解き方アニメ | 中学受験 19 ステージ・高校受験 6 ステージに steps を 追加。tier 0 に かならず あることを `tests/walkthrough_check.gd` で 見張る |
| 音 | BGM 3 曲(自前生成)・効果音 7 → 15・正解時の 光と はずみ・れんぞく正解で 音程が 上がる |
| 復習 | まちがえた 問題を 最大 40 問 記録し、あとの 出題に まぜる(`GameState.add_review`) |
| 今日の図形 | 日付から 決まる 1 問・れんぞく記録・ネタバレなしの 共有文(`core/daily.gd`) |
| 図鑑 | 進めた ステージの カード一覧(`core/zukan.gd` / `scenes/zukan.tscn`) |
| ストーリー | 話者の 絵を 表示(`ui/chars.gd`)・キーパッド入力に 変更 |
| たからのちず | 平行四辺形・ななめ折り・時計・多角形の 回を 作り直し |
| 島取り | 難易度と 出題範囲の 取り違えを 修正 |
| 検査 | `consistency_check` / `walkthrough_check` / `review_check` / `daily_check` を 追加 |
| そのほか | Web 書き出しの プリセットを 追加(アプリ本体の 動きには 影響なし) |
