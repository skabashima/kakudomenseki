# 課金登録情報 ― 図形ハンター

アプリ内課金は**買い切り1商品のみ**。サブスクリプション・消費型・広告は入れない。
コード側は実装済み(`core/iap.gd` / `scenes/store.tscn` / `addons/`)で、
**ストア側の商品登録だけで有効になります**。

実装は さわる物理(`sawarubutsuri`)で TestFlight まで通した構成をそのまま移植しています。
プラグインの罠(iOS のフレームワーク埋め込み・Android の JNI 内省不可・復元の固まり)への
対策はコードのコメントに残してあるので、消さないこと。

---

## 1. 無料 / 有料の線引き(このアプリの設計)

| | 内容 |
|---|---|
| **無料** | 角度編の先頭 4 ステージ + 面積編の先頭 4 ステージ = **8 ステージ**<br>(三角形の角・平行線と角・二等辺三角形・時計の針の角 / 正方形と長方形・三角形の面積・いろいろな四角形・円とおうぎ形)<br>タイムアタック(角度編)も無料。出題は無料ステージからだけ |
| **有料(購入で解放)** | 残り **57 ステージ**(全 65 = 角度編 20 + 面積編 45)<br>全ステージの「挑戦 10問」(王冠)<br>タイムアタック(面積編 / 全コースミックス)とサバイバル |
| **課金で制限しないもの** | 電卓入力・「解き方」アニメ・補助線・ヒント・★ / 段位 / 記録 |

境界は `core/game_state.gd` の `FREE_STAGES_PER_COURSE`(既定 4)一箇所で決まる。
変えたら解放画面の文言(残り N ステージ)も自動で追従する。

## 3. Google Play Console での登録

**収益化 → アプリ内アイテム → アプリ内アイテムを作成**

| 入力項目 | 値 |
|---|---|
| プロダクトID | `kakudomenseki_unlock_all` |
| 名前(55字以内) | 全ステージを解放 |
| 説明(200字以内) | 角度編・面積編あわせて全65ステージのうち、無料範囲をのぞく57ステージがすべて遊べるようになります。買い切りで、追加の課金はありません。各ステージの「挑戦10問」と、チャレンジのタイムアタック全コース・サバイバルも解放されます。 |
| 価格 | ¥500(日本) |
| ステータス | 有効 |
| 税区分 | 標準税率(アプリ内商品) |

**必要な準備**
- [ ] **課金権限入りの AAB を一度アップロード**(内部テストトラックで可)しないと商品を作成できない。
      入っていないと商品一覧に「請求権限を APK に追加する必要があります」と出て、
      「新しい APK をアップロード」しか押せない状態になる(さわる物理で実際に発生)
- [x] `export_presets.cfg` に Android(AAB)プリセットを追加済み。
      パッケージ名 `jp.snaplace.kakudomenseki`、`gradle_build/use_gradle_build=true`
      (Billing プラグイン v2 以降は gradle ビルド必須)、min_sdk 24 / target_sdk 36
- [x] `com.android.vending.BILLING` 権限はプラグインの manifest が持つ(手動追加は不要)。
      ただし **`addons/GodotGooglePlayBilling` を置いて `project.godot` の
      `[editor_plugins]` で有効にしていないと、権限ごと入らない**
- [ ] **ランチャーアイコンが未設定**(`launcher_icons/*` が空 = Godot 既定のアイコンになる)。
      提出前に `store/icon/` に `launcher_192.png` / `adaptive_fg_432.png` / `adaptive_bg_432.png` を
      作って `export_presets.cfg` に指すこと(さわる物理の `store/make_icon.py` が流用できる)
- [ ] 署名鍵(keystore)を用意する。**紛失も流出もアプリの寿命に直結する**ので、
      鍵はリポジトリに入れず別管理(さわる物理の `store/署名鍵の作り方.md` と同じ手順)
- [ ] 内部テスト用に**ライセンステスター**を登録(Play Console → 設定 → ライセンステスト)。
      テスターは実際の課金なしで購入フローを確認できる

> `permissions/internet=false` のままで問題ない。Google Play Billing は Play ストアアプリとの
> IPC で動くので、アプリ自身の INTERNET 権限は要らない(さわる物理と同じ設定)。

## 5. プライバシー申告(両ストア)

このアプリは**データを一切収集しない**(通信は課金処理のみ。セーブは端末内 `user://save.json`)。

### Google Play「データセーフティ」
| 質問 | 回答 |
|---|---|
| データを収集または共有しますか | **いいえ** |
| データは転送時に暗号化されますか | 該当なし(収集しない) |
| ユーザーはデータの削除をリクエストできますか | 該当なし(収集しない) |
| 広告IDを使用しますか | **いいえ** |

### App Store「Appのプライバシー」
- **Data Not Collected**(データを収集していません)を選択

### 権限
位置情報・カメラ・連絡先・ストレージなどは**一切使用しない**。

### 掲載に必要な文書
- **プライバシーポリシー**: `docs/privacy.html` に作成済み(このアプリ用に書き換えたもの)。
  GitHub Pages を `main` ブランチの `/docs` に設定すると
  <https://skabashima.github.io/kakudomenseki/privacy.html> で公開される。
  **その URL を Google Play / App Store 両方の「プライバシーポリシー」欄に登録すること**(両ストアとも必須)。
  内容を直したらこの HTML を直す(md の二重管理はしない)。
  iOS/Android の書き出しでは `docs/*` を除外しているので、アプリ本体には入らない
- **特定商取引法に基づく表記**: 日本で有料販売するなら用意しておく。
  さわる物理の `store/特定商取引法に基づく表記.md` が雛形になる
  (アプリ名・価格・問い合わせ先を差し替えるだけ)

## 7. コード側の構成(移植済み・触るときの注意)

| ファイル | 役割 |
|---|---|
| `core/iap.gd` | 課金マネージャ(オートロード `Iap`)。Android(Play Billing)/ iOS(StoreKit2)/ スタブの3層 |
| `core/game_state.gd` | `premium` の永続と無料/有料の判定(`needs_purchase` / `paid_stage_count` ほか) |
| `scenes/store.gd` / `.tscn` | 解放画面。すべての課金導線がここに合流する |
| `addons/godot-iap` | iOS StoreKit2(OpenIAP v2.4.1)。`.framework` を含む |
| `addons/GodotGooglePlayBilling` | Android Play Billing v3.2.0(AAR) |
| `tests/iap_gate.tscn` | 無料/有料の線引きとチャレンジのゲートを検証するテスト |

- **オートロードの順番が重要**: `GodotIapPlugin` を `Iap` より**前**に置くこと。
  オートロードは記載順に木へ入ってその場で `_ready` が走るため、後ろだと
  `Iap._ready` の時点で `/root/GodotIapPlugin` がまだ無く、iOS 経路を掴み損ねる
- **エディタ・エクスポートテンプレート・プラグイン AAR の Godot バージョンを揃える**(現行 4.7.1)
- PC / エディタでは `Iap` はスタブになり、解放画面の購入ボタンは
  「この端末ではストアに接続できません」と出る。ゲートの見た目だけ確認したいときは
  デバッグビルドでタイトル左下のトグルを使う
- 返金時に `premium` を自動で false へ落とすことはしない(取得失敗で解放が消える事故を防ぐため)
