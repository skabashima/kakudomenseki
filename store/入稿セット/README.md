# ストア入稿セット ― 図形ハンター

**このフォルダをそのままアップロードできる形**にしてあります。各フォルダの中は
掲載順に `01`→`08` でリネーム済みなので、まとめてドラッグ&ドロップすればその順で並びます。

| フォルダ / ファイル | 用途 | サイズ | 備考 |
|---|---|---|---|
| `GooglePlay_スマホ_1080x1920/` | Google Play スマホ用 | 1080×1920 | **2〜8枚枠。8枚ちょうど** |
| `GooglePlay_フィーチャーグラフィック_1024x500.png` | Google Play のヘッダ画像 | 1024×500 | **1枚必須** |
| `GooglePlay_アプリアイコン_512x512.png` | Play Console のアプリアイコン | 512×512 | **必須**(アプリ内のランチャーアイコンとは別) |
| `AppStore_iPhone6.9_1320x2868_必須/` | App Store iPhone 6.9インチ | 1320×2868 | **必須枠**(ここを出せば 6.5/5.5 は省略できる) |
| `AppStore_iPhone6.5_1284x2778/` | App Store iPhone 6.5インチ | 1284×2778 | 任意(古い端末の見え方を出したいとき) |
| `AppStore_iPad13_2048x2732_必須/` | App Store iPad 13インチ | 2048×2732 | **iPad 対応で配信するなら必須** |
| `AppStore_App内課金_審査用_1242x2208.png` | App内課金の審査用スクショ | 1242×2208 | **課金商品に必須**(掲載用とは別枠) |
| `AppStore_App内課金_プロモ_1024x1024.png` | App内課金のプロモーション用画像 | 1024×1024 | 任意。審査用の代わりにはならない |

> iPad が必須枠に入っているのは、`export_presets.cfg` の
> `application/targeted_device_family=2`(iPhone & iPad)で配信するため。
> iPhone 専用にするならこの値を変えて、iPad のフォルダは出さなくてよい。

App内課金の審査用スクリーンショット(1242×2208)は掲載用とは**別枠**です。
1024×1024 のほうは「プロモーション用画像」で別物なので、取り違えると弾かれます。
(合成前の中間出力は `store/screenshots/` に出ますが、アップロードするものは全部この
フォルダに揃えてあります)

## 掲載の並び(8枚)

最初の3枚で「何のアプリか」が伝わる順にしてあります。

| # | 画面 | 見出し |
|---|---|---|
| 01 | タイトル | 角度と面積を、数字で撃ち落とせ。 |
| 02 | 星形の角(挑戦モード・とがった角 4 つ) | 図で出る。数字で答える。 |
| 03 | 解き方アニメ(ヒポクラテスの月) | わからなければ「解き方」をアニメで |
| 04 | 道の面積(解答欄に式を入れた状態) | 式のまま答えられる。紙とペンいらず |
| 05 | 葉っぱ形に挑戦 | 中学受験の名物問題もそのまま |
| 06 | ステージ一覧(角度編) | 中学受験から大学受験まで一本道 |
| 07 | 記録 | 段位と★が積み上がる |
| 08 | 解放画面 | 買い切り。広告も追加課金もなし |

**図が単純にならないよう、tier(難度ラダーの段)を指定して撮っています。**
tier 0 は各ステージのいちばんやさしい変化なので、そのまま撮ると
「四分円ひとつ」「3・4・5 の直角三角形」のような絵になってしまう。
`tests/shot_store.gd` の `_problem/_calc/_walkthrough` の引数で tier を渡し、
tier 3 以上は挑戦モード扱いで出しています(ヘッダーが「挑戦: ○○」になる)。
電卓の画面だけは式を手で書いているので、**乱数の種を固定**し、
式の値が問題の答えと合うかをその場で検算しています(合わないと撮影ログに ★ が出る)。

差し替えたいときは `store/make_store_images.py` の `PICKS` を書き換えます
(素材は `store/raw/` に 10 画面ぶん、見出しは同ファイルの `SHOTS`)。
未使用の素材は「チャレンジ選択」と「ステージ一覧(面積編)」の 2 枚です。
撮る画面そのものを変えるときは `tests/shot_store.gd` の `_run()` を編集します。

## 作り直す手順

```
godot --path . res://tests/shot_store.tscn   # 実画面を 1320×2868 で撮る
python store/make_store_images.py            # 背景と見出しを合成し、この入稿セットまで作る
python store/check_store_images.py           # 寸法・枚数・容量・引き伸ばしの検品
```

- 撮影は **1320×2868**(App Store の必須枠と同じ最大サイズ)で行います。ここが最大なので、
  ほかのサイズは縮小だけで作れて画質が落ちません。PC の画面より大きい解像度は
  ウィンドウでは撮れないため、SubViewport に描いています(`tests/shot_store.gd`)。
- 端末画面は**素材より大きくしない**ようにしてあります。iPad(幅 2048)で
  横幅の 88 % に置くと引き伸ばしになるため、背景を広くとって等倍以下に収めます。
- 撮影時は進捗と購入済みの状態をその場で作って撮り、終わったら元に戻します
  (セーブはしないので、実際の進捗は変わりません)。
- 検品スクリプトが寸法・枚数・形式・容量・引き伸ばしを見ます。**目で確かめない**こと。
